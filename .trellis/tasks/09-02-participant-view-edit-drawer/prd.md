# 参与者查看与编辑侧边栏

## Goal

让管理员在参与者列表中直接通过“查看”和“编辑”按钮处理单个参与者，点击后从页面右侧打开对应侧边栏，减少离开列表页面的跳转成本。

## Background

- 当前参与者列表只有 Participant ID 详情页链接，没有独立操作列或行内操作按钮（`apps/admin-web/app/(console)/participants/page.tsx:73`）。
- 现有详情页已经展示参与者状态、Consent、区域、管理邮箱、默认设备和备注，并承载资料、邀请、状态与设备管理（`apps/admin-web/app/(console)/participants/[participantPublicId]/page.tsx:16`）。
- 现有参与者 API 已支持按 Public ID 获取详情和 PATCH 更新资料，更新时要求 `expectedUpdatedAt` 以防止过期写入（`apps/admin-web/app/api/admin/participants/[id]/route.ts:11`；`packages/core/src/server/services/participants.ts:59`）。
- 公开 Demo 管理员不能修改 Fixture 参与者；侧边栏编辑必须继续遵守此保护规则（`packages/core/src/server/services/participants.ts:123`）。

## Requirements

- R1：参与者列表增加“操作”列，每行提供“查看”和“编辑”两个明确按钮。
- R2：点击“查看”后，从页面右侧打开查看侧边栏；查看态为只读，展示 Public ID、Alias、状态、Consent、管理邮箱、国家/地区、Locale、时区、默认设备、备注、Fixture 标记，以及管理员可重复查询的参与者登录帐号和密码。
- R3：点击“编辑”后，从页面右侧打开编辑侧边栏；首版只允许编辑 Alias、管理邮箱、国家/地区、Locale、时区和备注，并复用现有参与者 API 校验。
- R4：侧边栏可通过关闭按钮、遮罩和 Escape 关闭，并在关闭后将焦点返回触发按钮。
- R5：移动端侧边栏占满可用宽度，桌面端保持适合表单阅读的有限宽度；打开时页面背景不可滚动。
- R6：提交期间禁用重复提交并显示保存状态；失败时在侧边栏内显示错误；成功后关闭侧边栏并刷新列表数据。
- R7：Fixture 保护、并发更新检测以及服务端授权保持现有行为，不在前端绕过。
- R8：登录帐号使用 Participant ID；支持分别复制帐号、密码，以及一键复制参与者站点登录地址、帐号和密码组成的完整登录信息。
- R9：参与者密码通过授权的单参与者详情接口按需读取，不进入分页列表结果、URL、日志、错误信息、审计 payload 或浏览器持久化存储。
- R10：没有可查密码的既有参与者显示“生成登录密码”；管理员确认后调用凭据接口生成并同步重置 Supabase Auth，随后在侧边栏内显示并可复制。已有可查密码的参与者显示“重置登录密码”，并明确提示旧密码会失效。

## Acceptance Criteria

- [x] AC1：列表表头出现“操作”，每行可见“查看”和“编辑”按钮。
- [x] AC2：点击“查看”时，在当前列表页右侧看到该参与者的只读资料，无需页面跳转。
- [x] AC3：点击“编辑”时，在当前列表页右侧看到该参与者的可编辑资料表单。
- [x] AC4：保存合法修改后，侧边栏关闭，列表显示最新资料，并且后端仍记录现有审计信息。
- [x] AC5：无效输入、请求失败或过期写入不会静默关闭侧边栏，管理员能看到可操作的错误提示。
- [x] AC6：公开 Demo 管理员查看 Fixture 正常，但编辑入口或表单不可执行保存，并提供原因提示。
- [x] AC7：键盘用户可以打开、操作和关闭侧边栏；侧边栏具有可识别标题和模态语义。
- [x] AC8：现有 Participant ID 详情页入口和详情页功能继续可用。
- [x] AC9：管理员稍后重新打开查看侧边栏时仍能查找并复制该参与者当前登录帐号和密码；复制完整信息后可直接发送给参与者使用。
- [x] AC10：未授权请求、参与者端请求和批量列表响应均无法取得其他参与者密码，管理端账号密码不受影响。
- [x] AC11：既有参与者在管理员确认前不改变旧密码；生成或重置后，侧边栏显示的新密码能用于参与者登录，旧密码不可再登录。

## Out of Scope

- 改变管理端账号密码的存储或验证方式。
- 在侧边栏内管理邀请、参与者状态、设备或退出研究等高风险操作。
- 删除现有参与者详情页。

## Key Decisions

- 侧边栏首版聚焦快速查看和基础资料编辑。
- 状态、邀请、设备和退出研究等高风险操作继续在完整详情页完成。
- 保留 Participant ID 的详情页链接，为管理员提供完整管理入口。
- 参与者凭据按产品决策作为管理员可重复查询的运营信息处理；该决策不扩展到管理端凭据。

## Notes

- 凭据持久化、Supabase Auth 同步与审计由独立子任务负责；本任务负责侧边栏中的展示和复制集成。
